Tento projekt predstavuje jeden segment LED displeja, ktorý je
súčasťou časomiery. Riadiaci mikrokontrolér ESP32 zabezpečuje
presné ovládanie jednotlivých LED diód pomocou digitálnych
signálov. Hlavným cieľom projektu je vytvoriť základ pre
viacmiestny LED displej, ktorý dokáže zobrazovať celé čísla.
Projekt demonštruje praktické využitie ESP32 v oblasti elektroniky,
programovania a automatizácie.
